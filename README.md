# Thai Sign Assist

A real-time Thai Sign Language phrase recognition prototype
using computer vision and deep learning.

## Project Goal

The project aims to recognize a limited set of practical Thai
Sign Language phrases from webcam video and convert them into
Thai text.

## Current Progress

- [x] Project environment
- [x] Webcam capture
- [ ] Hand and body landmark detection
- [ ] Feature extraction
- [ ] Dataset collection
- [ ] GRU/LSTM model
- [ ] Real-time recognition
- [ ] User interface

## Planned Pipeline

Webcam → MediaPipe → Landmark Sequence → GRU/LSTM → Thai Phrase
